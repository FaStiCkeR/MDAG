# Алгоритм Беднарека и Толби для нахождения Наибольшего Внутренне Устойчивого Подмножества (НВУП)

## Основные обозначения

Для графа $G$ с $n$ вершинами введём следующие обозначения:

- $V_k = \{x_1, x_2, \dots, x_k\}$ — множество первых $k$ вершин.
- $S_k$ — семейство **максимальных** независимых (внутренне устойчивых) множеств для подграфа, порождённого множеством
  вершин $V_k$.
- $A_k = \{\, x_j \in V_{k-1} \mid x_j \text{ не смежна с } x_k \,\} \cup \{x_k\}$.

## Пошаговое описание алгоритма

**Шаг I (Инициализация):**  
Полагаем $k = 1$, $S_0 = \{\varnothing\}$, $V_0 = \varnothing$.

**Шаг II:**  
Формируем множество  
$$A_k = \{\, x_j \in V_{k-1} \mid x_j \text{ не смежна с } x_k \,\} \cup \{x_k\}.$$

**Шаг III:**  
Строим семейство множеств  
$$Q_k = \{\, M \cap A_k \mid M \in S_{k-1} \,\}.$$  
Каждый элемент семейства $Q_k$ является независимым множеством в подграфе $V_k$.

**Шаг IV:**  
Определяем $Q_k^*$ — семейство всех максимальных множеств из $Q_k$ (по включению).

**Шаг V:**  
Строим семейство множеств $R_k$, анализируя каждый элемент $M \in Q_k^*$:

a) если $x_k \notin M$, то $R_k \leftarrow R_k \cup \{M\}$;  
b) если $x_k \in M$, то $R_k \leftarrow R_k \cup \{M\}$, и если при этом $A_k \not\subseteq M$, то дополнительно
добавляем множество $M \cup (A_k \setminus M)$.

**Шаг VI:**  
Определяем $S_k$ как семейство всех максимальных (по включению) множеств из $R_k$.

**Шаг VII:**  
Если $k < n$, то полагаем $k \leftarrow k+1$ и переходим к шагу II.  
В противном случае $S_n$ содержит все максимальные независимые множества графа $G$. **Останов.**

# Суть алгоритма

_Мы строим максимальные независимые множества постепенно, добавляя вершины по одной и обновляя семейство допустимых множеств._

## Как работает (простыми шагами)
### 1. Старт
Берём:
1. Пустое множество
2. Начинаем с первой вершины
### 2. Для каждой вершины $x_k$
Мы делаем 3 вещи:
1. Определяем допустимые вершины которые не смежны с $x_k$
2. Пересекаем их с текущими множествами и оставляем только совместимые варианты
3. Расширяем множества добавляя $x_k$, если это возможно
### 3. Фильтруем
Оставляем только:
1. Максимальные по включению множества
### 4. Повторяем до конца вершин
Итог
В результате получаем все максимальные независимые множества графа, 
а среди них — наибольшие, размер которых равен числу независимости α(G).

Алгоритм Беднарека–Толби строит семейства независимых множеств по шагам, добавляя вершины по одной. 
На каждом шаге формируются допустимые расширения текущих множеств, после чего остаются только 
максимальные по включению множества. В результате на последнем шаге получаются все максимальные 
независимые множества графа, а наибольшие из них дают число независимости α(G).

### Коротко:
Это итеративный алгоритм построения максимальных независимых множеств через последовательное добавление 
вершин и фильтрацию по включению.

## ВАЖНОЕ ПОНИМАНИЕ
1. Это не перебор всех подмножеств
2. Это постепенное построение семейств множеств

# Термины

* Независимое множество вершин — набор вершин, в котором никакие две не соединены ребром (как гости на вечеринке,
  которые не знакомы друг с другом).

* Максимальное независимое множество — такое независимое множество, к которому нельзя добавить ни одной вершины графа,
  не нарушив условие «никаких рёбер внутри». (Это не обязательно самое большое по размеру, но «нерасширяемое».)

* Наибольшее независимое множество — самое большое по количеству вершин среди всех максимальных.
* $V_k$ — Первые k вершин графа, используется для построения по шагам
* $S_k$ — Семейство всех максимальных независимых множеств на шаге k, ключевой объект алгоритма
